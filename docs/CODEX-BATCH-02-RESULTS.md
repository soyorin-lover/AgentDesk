## 关键回归与修复

均先观察失败，再修复为通过：

1. 旧轮次先到终态不能消费新轮次的等待；RPC 明确拒绝保留数字错误码，与超时区分。
2. SSE write(false) 不再立即销毁大事件；等待 drain，并对慢客户端有界断开。
3. Windows Git staged 120000 模式即使物理普通文件也视为符号链接，不允许接受。
4. 摘要采用带类型和长度的编码，区分字面内容 deleted 与文件删除，并防止路径/内容跨文件拼接碰撞。
5. 真正完成状态等待直属执行进程关闭；关闭未确认则 needs_recovery 并隔离工作区，不允许后续扫描接受或新执行。
6. SQLite 事件写入故障使后端停止动作，事务回滚；重启将未完成运行标为未知，不自动重发。
7. 令牌写入失败正确关闭 HTTP 和数据库/工作区租约；服务进程被强制结束后，记录和租约可恢复查询，模型任务不自动重放。
