# 协作与工作区

同一个 Git 仓库，不同写代码的执行者使用独立 worktree。当前只有主工作区，尚未创建额外 worktree。

## 分工

2026-10-09 用户更新：Codex 接手前端 UI、交互及联调，已有专门前端对话；本主对话继续负责后端、接口与整体协调。Claude 后续需要时再使用。下方原三方分工为历史，不再限定前端只能由 Claude 修改。产品新基线见 [已确认工作流](PRODUCT-DECISIONS-2026-10-09.md)。

Codex：执行接入、后端、任务状态、Git、数据库、集成和测试。
Claude：前端设计、页面、组件、交互与前端测试。
DeepSeek：示例数据、文案和简单文档，不要求本地工作区。

Claude 网页设计阶段无需本地目录。Claude Code 开始并行编辑代码时再建立独立 worktree；不要手工复制三份互不关联的项目。

## 共享内容

共享接口、根级配置、依赖锁文件需指定本批修改者。第一批由 Codex 维护根级配置；Claude 先交付原型与数据需求。

产品说明、批次任务、接口约定通过 Git 提交和同步传播。worktree 不会自动收到其他工作区的未提交修改。任务交接注明基准提交和变更提交。

## 集成

每批先检查任务分支的 diff 和验证结果，再集成到主工作区。接口不匹配先协调，不绕过检查。

开发端口、运行数据库、临时输出分别隔离。worktree 不能隔离操作系统权限、进程、外部服务或凭据，不作为安全沙箱。
