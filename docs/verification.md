## 失败与修复

1. **私有快照缺失。** 交付 fixture 实际报 ENOENT，加入回归观察失败，再切换当前源码并比较公共三文件哈希，回归转绿。
2. **启动权限不符。** 首次验收在 turn 开始前返回 readOnly 而阻塞。无模型元数据对照表明，经平台审批启动返回 workspaceWrite。保留严格校验，并加首次/续接拒绝回归，没有取消安全条件假装修复。
3. **默认上游断流。** 新样例进入 turn，出现 4 条 responseStreamDisconnected 与 1 条其他网络诊断，约 120 秒后未知。应用未重发，但 CLI 内部重连，default 不能被称为从不重试。无文件修改、未反馈或接受，具体 WebSocket/代理/TLS 根因未确定。
4. **HTTP 验收。** 依据历史成功条件使用已有 HTTP 选项，关闭请求/流重试，在用户重新授权的新样例完成两轮。辅助脚本最初在任何模型提交前退出，原因未确定；保留报告，本地只读检查通过后继续。此前两个未知任务的数据库没有改写或清除。
5. **验证工具偏差。** 强制 autocrlf=false 的样例 Git helper 曾误报换行变化，换用后端 Git 配置确认无实质修改；浏览器脚本曾等错文案而超时，改用实际回复定位后通过。未将它们伪装成产品缺陷。
