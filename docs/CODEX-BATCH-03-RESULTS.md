## 已交付

- 可信项目模式，保留 legacy workspace。配置只在本机提供真实路径；浏览器仅提交 projectId。项目有 HEAD、首次干净；工作区根真实路径与 source/main 无祖先重叠，含 Windows 大小写和 junction 检查。
- 创建多项任务；显式准备各自 Git worktree/codex 分支，固定 baseHead。先写 durable intent/idempotency，再 Git，最后记录结果。冲突不复用陌生目录；Git 后存储失败及重启中断不重复创建、不自动清理或假装 ready。归属已确认的中断也仍需人工恢复。
- 独立 cwd、会话、反馈、事件游标、快照及接受。全服务模型/检查串行，无排队。任务工作区与源仓库均有合作租约；退出未知持续阻塞。
- 单独 CheckRun，可信预设参数数组/shell:false，固定实际执行命令；真实子进程的成功/失败/取消/超时、stdout/stderr 总字节限额与 UTF-8 截断。无命令拼接或依赖安装；`.cmd`/`.bat` unavailable。
- status 与 validity 分开，重新核对内容/HEAD/index 和任务最新 run/snapshot。检查自己改文件、外部修改、新模型运行、新快照都不能保留旧绿色结论；扫描期间变化明确不完整。
- 项目列表、准备、检查/取消、检查读取与任务过滤接口；公共浏览器客户端同步并保留旧调用。接口、请求响应、状态映射见 [BACKEND-BATCH-03-API.md](BACKEND-BATCH-03-API.md)。
