# 产品范围 v0.3

2026-10-09 最新用户确认见 [产品与工作流决定](PRODUCT-DECISIONS-2026-10-09.md)，这是当前产品设计基线。当前实现和验证范围见后端批次结果，目标不等于已实现。

## 目标

面向开发者的多 Agent 协作管理中心：在同一项目下组织不同分工的 Agent，通过流程图、任务会话、进展、提醒和交接，减少多窗口切换及工作遗漏。开发者保留指挥权，负责人 Agent 提议、用户确认后执行。首版目标支持 Codex、Claude、DeepSeek Harness，逐个接入与验证。

## 首版约束

单用户、本机运行，支持 Windows / Linux，交付给其他开发者经过简单配置即可使用。软件自动处理本机服务和内部连接；不是要求用户手动启动前后端的开发演示。IDE 和终端保持外部工具，不做完整 IDE。

首批先验证 Codex 是实施顺序，不限制长期产品范围。目前只有 Codex 具有本项目真实接入证据；Claude Code、DeepSeek Harness 的具体产品版本、接入协议与能力均需另批核验，不展示为已接入。

## 多引擎设计边界

- 项目、任务、工作区、执行记录、变更与交付属于工作台通用概念，不以 Codex 协议直接定义全部产品界面。
- 执行引擎（例如 Codex / Claude Code / DeepSeek Harness）、配置的智能体实例、所用模型和具体会话分别表达；更换模型不等于切换引擎。
- 通用界面展示引擎与实例身份；事件和动作通过各引擎适配。审批、中止、补充指令、恢复等能力分别验证并明确支持情况，不假定三个引擎完全一致。
- 会话恢复在所属引擎内进行；跨引擎交接需显式传递任务说明、代码与证据，不假定可以迁移原生会话上下文。
- 角色配置复用；开发任务对应独立会话和 worktree，同一种工具可并行承担多项任务。负责人从项目成员中指定，方案及结构调整经用户确认，支持整批或部分批准；未授权工作不自动执行。

## 已确认的视觉与交互方向

浅色、安静、精致、现代简洁。默认入口为全局项目管理首页，进入项目后以流程图/树形图表达工作、角色、状态和依赖。节点详情和会话同一工作视图呈现，辅助信息按需展开；默认单会话，可临时并排。保留阅读位置、草稿与图位置，不固定常驻三栏。

前端重设计先确认关键画面与信息层级，再铺开实现。面向多引擎设计导航和身份展示，当前原型与真实接入状态始终分别标示。

完整应用设计讨论稿见 [DESIGN.md](DESIGN.md)。它区分用户已确认要求与方案建议；具体导航、页面和视觉数值尚待评审，不作为立即重写前端的实施指令。

## 核心闭环

项目管理 → 新建项目空间或接入已有开发中仓库 → 确认现状与代码基线 → 手动/负责人生成流程和分工 → 用户批准 → 各任务独立 worktree 并行开发 → 提醒、反馈、审查、人工确认 → 显式交接 → 经批准集成到专用分支与联合检查。

首版目标包含并行任务、依赖及负责人辅助规划；实现仍分批推进。无人工批准的自主调度、自动验收属于后续增强。已有代码可直接接入，不要求补录全部开发历史；不自动纳入未提交改动或声称已有功能已验证。

## 三个工作区视图

1. 项目与任务：环境状态、任务、运行情况和待处理事项。
2. 任务工作台：目标、验收条件、会话、执行时间线、问题和审批。
3. 变更与交付：文件 diff、检查证据、反馈、集成结果。

## 状态

任务：草稿、就绪、处理中、待审查、已接受、已集成、已验收、已取消。
运行：排队、运行中、等待用户、成功、失败、已中止、待恢复。
阻塞原因单独记录。执行成功不会自动代表任务验收通过。

## 产品规则

- 关闭软件且存在执行任务时询问后台继续或停止执行并退出；关闭单个会话视图不取消任务，中止不回滚已有改动。
- 内部角落弹窗不抢焦点，后台使用系统通知，点击定位任务；关闭提醒后标记保留至事项真正解决。
- 恢复会话与重跑不同；不承诺恢复已终止的系统进程。
- 每项检查展示真实命令、退出结果和输出，未检查明确标示。
- 合并进入专用集成分支，不自动推送或部署。
- 原型、模拟执行和真实执行明确区分。

## 暂不实现

多租户、计费、完整 IDE、模型训练、自动发布以及自动解决所有合并冲突。三种 Agent 属首版目标，但现有 Codex 批次完成不代表其他引擎完成，按独立批次接入。

## 后续架构基线

已有前端 React / TypeScript，后端 Node.js / TypeScript、SQLite、Git worktree，执行层按引擎适配。其他引擎协议、桌面宿主、通知和后台常驻方案待独立核验。Codex 已接手前端 UI 与后端，后续按需要使用 Claude；不自动改动共享接口或重写已有实现。
