# 第 1 批实施设计与记录

目标：按 CODEX-BATCH-01.md 交付可重复运行的 CLI 验证器，证明真实协议能力与限制。范围不含 HTTP、数据库或前端。

采用 Node.js >=24.17 的内置 TypeScript 类型擦除与 node:test；无运行依赖。相比引入 SDK 或完整后端，直接 JSONL 客户端便于检查本机版本和故障边界。所有子进程使用参数数组和 shell:false。Codex 路径由 CODEX_BIN 或 PATH 提供。

文件职责：src/codex/rpc.ts 管理 JSONL、关联 ID、超时、事件与服务端请求；src/codex/session.ts 管理握手和轮次；src/verify.ts 编排专用 Git 示例仓库、真实调用与摘要；tests/ 使用真实 Node 子进程作为确定性协议对端。运行产物仅在 .agentdesk/ 下，不保存原始认证、模型日志或命令输出。

## 实施顺序

- [x] 协议层：先失败测试（分片 UTF-8、乱序响应、错误、重复服务端请求、超时、退出、非法消息），再实现并运行全套测试。
- [x] 会话层：测试握手顺序、完成通知早于响应、轮次失败和中止；实现事件观察与等待器，避免监听竞争。
- [x] CLI：在唯一命名的示例 Git 仓库提交固定初始文件；仅对该目录发起任务。验证文本、修改 diff、上下文、重连恢复、steer/interrupt、审批、并行隔离。每阶段保存脱敏标识与断言；失败阶段后仍保存证据并清理自有服务进程。
- [x] 最终验证：运行测试、可用的静态类型检查、真实验证、Git 状态与自有进程检查；独立只读审查；更新能力矩阵、README、Claude 交接及 HANDOFF。

## 关键边界

请求超时不等于取消服务端动作；中止必须收到 interrupted。审批默认拒绝，接受仅允许本次受控示例文件动作，不接受会话级授权。未知服务端请求返回协议错误。正常退出先关闭 stdin，超时只终止自有子进程并记录结果。恢复会话不恢复已结束的 shell 进程。模型沿用服务器默认配置，不猜权限。

示例仓库保留所有未提交修改；不自动提交、推送或清理主仓库。当前仓库无初始提交，单写入者在现有目录实现；研究与审查子代理只读。Linux 需要单独环境，不以 Windows 替代。
