# 首个公开版本范围与验收条件

日期：2026-10-12（Asia/Shanghai）。阶段：P1 需求基线。原型基线：`837d5d0`。

本文收紧首个公开版本，不替代长期产品方案，不代表功能已验收。状态依据是现有交接与结果记录，P2/P3 再核对代码，P4 再收集本交付仓库的运行证据。

## 用户、问题与交付形态

面向使用 Coding Agent 修改已有 Git 项目的个人开发者。用户需要把任务要求、批准、执行会话、代码变化和检查依据放在同一流程中，知道执行了什么、结果是否可信、接下来需要自己决定什么。

首个公开版本交付 Windows 本机、单用户、串行的 Web 工具，沿用 Node.js / TypeScript / SQLite 后端和 React / Vite 前端，只把 Codex 纳入真实主线。使用者自行安装和配置合法可用的 Codex、Git、Node.js；启动方式沿用现有前后端脚本，整理成可复现的 README，不要求新增一键启动器或安装包。

用户此次明确选择：必须支持“结果不满意 → 提出修改要求 → 继续同一任务”。真实验收因此至少包含首次执行和一次反馈执行；真实调用仍须在 P4 明确小任务及预算后进行，P1 不启动调用。

## 三个必须跑通的场景

| 场景 | 用户预期 | 可观察的验收条件 |
| --- | --- | --- |
| 1. 安排一次已有项目的修改 | 接入已有 Git 仓库，写任务与验收条件，审阅后明确批准 | 能查看仓库状态与基线 commit；导入不覆盖、重置或自动提交原目录；保存计划不等于批准，批准不等于启动；下发前能核对任务、Codex 实例、独立工作区和基线 |
| 2. 执行并提出修改要求 | 查看 Codex 的真实执行结果，不满意时继续原任务 | 有持久任务/运行记录；明确区分请求被接受、执行中和确定终态；首次执行后发送一条修改反馈，服务证据证明归属同一任务及原生会话，不偷偷新建会话兜底；执行中不能即时发送时明确说明并保留本页草稿 |
| 3. 根据证据接受成果 | 看清代码变化，运行检查，决定是否接受 | 可查看对应成果快照的 Diff、检查命令、退出结果和输出；检查通过与人工接受分别呈现；接受关联具体成果版本；继续执行或工作区变化后，旧证据不能被冒称为当前有效；接受不自动合并、推送或部署 |

演示使用无敏感信息的小型示例 Git 仓库，避免拿真实私人项目作为公开演示数据。真实 Agent 验收与确定性 fixture 验收分别记录，不能互相替代。

## 必须覆盖的保护与失败分支

以下是发布验收要求，尚不是当前实现的结论。优先复用已有测试与确定性 fixture，不为每个分支调用模型。

| 条件 | 预期与证据 |
| --- | --- |
| 原仓库有未提交改动 | 明确提示它们不自动进入任务 worktree；准备和执行均不覆盖原目录；最终比较原目录状态 |
| 修改已批准的计划 | 新修订不能沿用旧批准启动；历史任务保留可解释的只读访问；通过既有版本与授权测试核对 |
| 服务已有活动任务 | 第二个启动请求被明确拒绝或禁用，不伪装已执行或已排队；不承诺并行与自动队列 |
| 执行明确失败或结果未知 | 界面显示失败或未知及下一步限制，不当作成功，不自动重发模型请求；未知会话归属时不允许反馈新会话回退 |
| 检查失败或检查后代码变化 | 保留真实失败结果；旧检查显示过时或不可验证，不能把旧通过报告当作新代码的通过证明 |
| 接受后继续执行或修改文件 | 旧接受不能继续显示为当前有效；重新审查具体版本；不会回滚文件或自动集成 |
| 页面刷新或连接异常 | 能重新读取已保存的任务事实；未能确认的请求不直接显示成功；断线时不提供依赖过时事实的不安全写操作。跨退出保留草稿、画布位置和阅读位置不作为首版承诺 |

发布演示中的示例任务必须满足预先约定的验收条件，并有当前有效的检查证据后再人工接受。这是演示的验收流程，不预先宣称产品已实现“所有检查失败均强制禁止接受”的通用规则；实际门禁在 P3 核对。

## 发布门槛与后续工作

- P2：把主线映射到现有页面、API、服务、数据库、Agent 与 Git，解释状态和版本关系，确定前后端配套方案。
- P3：按模块核对上述条件；仅修复发现的实际阻塞问题。无法满足时记录原因，与用户调整范围，不能静默删去必须场景或冒称通过。
- P4：在明确代码版本上完成真实首次执行与一次反馈续接；其他关键分支使用确定性证据；运行必要测试、类型检查和构建。从干净检出按 README 启动，说明必须的工具与配置。
- P4：完成 README、示例配置、许可证和素材来源检查、公开文件复核、限制及演示。未配置的检查不报告为通过；历史日志不默认发布。
- GitHub 公开发布仍需在准备完成后明确处理；本范围文档不授权现在推送、发布、调用模型或扩展上述排除功能。
