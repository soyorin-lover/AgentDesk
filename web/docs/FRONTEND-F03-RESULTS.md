# F03：B07 项目流程、明确批准与节点人工确认

日期：2026-10-09。状态：本批实现与验证完成。

## 实现范围

本批消费正式 B07 公共客户端，在前端工程完成项目角色、成员、负责人、父子层级及执行依赖图。父子层级不决定执行顺序；拖动、缩放与视口保存只改变布局，层级树提供键盘等效入口。Claude / DeepSeek 保留为配置目标，执行能力仍由服务判断；不猜测实际模型。

全量草案编辑覆盖名称、目标、逐行验收、角色与成员、工具实例、父节点、执行依赖及固定执行绑定。提交前明确审阅变化与旧批准撤销；服务返回的 affectedNodeIds 和 authorizationInvalidatedNodeIds 独立展示。任何新修订都会停止旧批准的后续授权，历史任务、会话与代码入口保留；旧受管任务不能重新关联。

全量剩余批准与部分批准均提交明确节点集合。部分集合缺少依赖时显示缺失 ID 并禁止提交，不自动扩大集合；已批准节点不重复提交。批准不创建任务、准备工作区或启动运行。节点任务须另行审阅后创建，或明确输入完全匹配的同项目普通任务 ID；标题、目标、验收、实例及固定绑定均由服务重新验证。

运行成功、检查通过和代码接受均不自动完成节点。只有当前有效接受及本次批准后的运行证据，加上独立人工确认，才能由服务返回 completed。反馈、外部修改与依赖失效后的状态继续取服务当前事实，保留实际进行中状态；人工确认不代表代码集成或最终验收。

流程版本独立于项目版本，版本 0 有效。写入回执保留为历史回执，每次写入后重新 GET 当前流程；读取期间禁止新写入。未知结果保留原项目、原版本、原正文和原幂等键，跨项目可导航回原请求重试；冲突保留本地草稿，须显式采用当前版本并重新审阅。取消旧读取、读取序号、版本单调检查及生命周期代际隔离防止迟到响应覆盖当前项目。

没有流程 SSE。任务事件变化触发流程重读，当前项目每 5 秒受控重读一次；隐藏页面跳过，读取/写入中跳过，离开项目或连接卸载时释放定时器和订阅。节点进入已有任务工作台，返回时恢复图布局与视口。
